# 深夜台灯 · Lamp Login

[English → README.md](./README.md)

一个有性格的登录页：房间是暗的，**拉一下灯绳（或按 `L`），台灯亮了才能登录**。

**在线体验 → <https://phj2001.github.io/Desk-Lamp-Login-Page/>**

已支持中英双语——自动跟随浏览器语言，右上角 `中 / EN` 可随时切换。

## 交互彩蛋

- 🪢 **拉灯绳开关灯**：拖拽灯绳超过一定距离松手即可切换，轻点灯绳也行；灯绳有回弹物理，灯体会像钟摆一样轻轻晃动
- 💡 **钨丝点亮闪烁**：开灯瞬间灯光会像老灯泡一样闪几下才稳定，每次点亮随机换一种灯色
- 👀 **台灯有表情**：瞳孔追踪鼠标、随机眨眼；输入密码时它会眯起眼睛"偷看"；密码错误会吓一跳；登录成功会开心地眯眼微笑
- 🌑 **黑暗是真的黑**：灯没亮时登录卡片"看不清"——文字变成一片模糊的色块，鼠标只剩一小圈手电筒似的微光；摸黑点它，台灯会晃晃灯绳提醒你
- 😴 **它会打瞌睡**：太久没动静，台灯会歪着头睡着，灯光慢慢变暗，头顶飘 Zzz；动一下鼠标它就醒
- 🙄 **它会无语**：连续输错 3 次密码，它从"吓一跳"升级成"半睁眼冷汗"，灯色都气得泛红；错第 4 次它会忍不住提示你正确答案
- 🫣 **它怕痒也怕生**：戳戳灯罩它会果冻似的抖起来偷笑；鼠标凑得太近，瞳孔会害羞地躲开
- ⏰ **它会催你**：灯黑着不管它，它会隔一阵自己晃晃灯绳："喂，拉我一下"
- 💥 **隐藏彩蛋**：短时间内连拉 5 次灯绳，灯泡会"啪"地烧掉——房间全黑、青烟袅袅、星空变亮、萤火虫飞出来；它摸黑换好新灯泡后会求你温柔一点
- 🎬 **谢幕**：登录成功后卡片缓缓退场，屏幕中央亮起"晚安，欢迎回来"
- 🔊 **音效**：WebAudio 实时合成——开关"咔哒"、成功风铃、无语叹气、偷笑咯咯声、灯泡烧掉的"啪"

演示账号：`admin` / `123456`

## 技术

Vue 3 (`<script setup>`) + Vite + GSAP (Draggable)。无后端；双语层没有引入 vue-i18n，只是一个 `ref` 加一份字典。

灯光系统基于 CSS `@property` 注册的 `--on` / `--shade-hue` 两个自定义属性——它们本身可过渡，因此全站几十处依赖灯光的颜色、阴影、透明度都会自动平滑联动，无需逐个写过渡。打瞌睡的渐暗、灯泡烧掉的瞬灭、被气到的泛红，只是给 `<html>` 换一档 `transition` 速度而已。

其他：灯绳可聚焦、支持回车/空格开关灯；支持触屏拖拽；尊重 `prefers-reduced-motion`。
